# Task-Completion-Dashboard
The Task Completion Dashboard provides a clear, visual overview of task progress and performance across different activities. It highlights the overall distribution of completed, pending, and not completed tasks, helping stakeholders quickly understand current status.

# 📊 Task Completion-Dashboard:

## 🔍 Project Description
This project main idea is to **Track the progress and performance across different activities** and this was created using **Microsoft Excel**,**Power automate**,**Sharepoint**.  


## 🎯 Key Insights
- performance Tracking
- automate flow for tracking
- Key excel visualization
- Interactive filters and slicers

## 🛠 Tools Used
- Excel / CSV (Data Source)
- sharepoint
- power automate
